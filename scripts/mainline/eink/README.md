2026-10-15. Status: compiles (W=1, no warnings) against linux 7.2.10 + patches 0001-0005, offline tests pass,
**never run on the phone**. Design, safety and the first-enable procedure: [docs/mainline-eink-driver.md](../../../docs/mainline-eink-driver.md).

## Integration (for the owner of `scripts/mainline/kernel/`)

1. `git am` 0006-0009 after 0001-0005 (or run `sync-tree.sh` for 0007 and commit).
2. `a9.config`: `CONFIG_DRM_A9_EINK=m` (it selects `CONFIG_DRM_CLIENT`; fbdev emulation stays off).
3. DTS: apply `dts/0001-...patch` (node `eink-display`, `toshiba,dsi-hse`, vdda comment).
4. Module set for the initramfs: `a9_eink.ko` after `msm`, `tc358767`, `panel-hisense-hlte556n-eink`
   (it needs `drm_shmem_helper`, `drm_kms_helper`). It may load before msm: it attaches to the msm card at the
   first update.
5. Waveform: `make -C scripts/mainline/eink && build/a9wf-extract <composer> <out>`; install `<out>` as
   `/lib/firmware/hisense/a9-waveform.bin` in the initramfs from a path **outside git** (e.g.
   `~/A9-build/mainline/firmware/`). The resulting image contains vendor tables: keep it local.
   Control template the same way: `nix-shell -p 'python3.withPackages(p:[p.unicorn p.pyelftools p.numpy])' --run
   'python3 -I tools/a9ct-extract.py <composer>'` writes `~/A9-build/mainline/firmware/hisense/a9-ctrl-template.bin`
   (payload sha256 a88ae8ef...; refuses other composers and paths inside git) -> `/lib/firmware/hisense/a9-ctrl-template.bin`.
6. `tools/a9eink-pattern.c` into the initramfs `/bin` (static; the glibc cross gcc has no static libc, musl
   does): `nix-shell -p pkgsCross.aarch64-multiplatform-musl.stdenv.cc --run 'aarch64-unknown-linux-musl-gcc
   -static -O2 -I<build>/usr/include -o a9eink-pattern tools/a9eink-pattern.c'` (after `make headers`).
7. Never put `a9_eink.enable=1` (nor the two power gates) on the command line; open them at runtime only.
